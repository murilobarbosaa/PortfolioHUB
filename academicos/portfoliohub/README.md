# PortfolioHUB

> Repositório versionado que reúne meus projetos acadêmicos e pessoais, publicado no GitHub Pages.

**Seção:** Acadêmicos · **Tipo:** repositório e site estático · **Status:** publicado

## Resumo

Projeto da atividade "Desafio, Entrega Intermediária: Criação de Repositório com Versionamento (PortfolioHUB)". O objetivo é organizar os projetos em um único repositório público, com versionamento Git, README por projeto, página no GitHub Pages, slides e integração com o LinkedIn.

## Problema

Projetos espalhados em pastas locais, repositórios privados e documentos soltos são difíceis de apresentar para professores, recrutadores e colegas.

## Solução

- Um repositório público dividido em seções: acadêmicos, pessoais e documentação.
- Uma pasta por projeto, cada uma com README padronizado.
- Uma página no GitHub Pages, feita com HTML, CSS e JavaScript puros, com modo escuro e layout responsivo.
- Slides em HTML na pasta `docs/slides/`, usados como roteiro do vídeo de apresentação.
- Versionamento com tags e releases (`v1.0`, `v1.1`), branches por funcionalidade e pull requests.

## Tecnologias

Git, GitHub, GitHub Pages, GitHub CLI, HTML, CSS e JavaScript.

## Meu papel

Planejamento, estrutura do repositório, textos, página e slides.

## Como acessar ou rodar

- Site: https://murilobarbosaa.github.io/PortfolioHUB/
- Slides: https://murilobarbosaa.github.io/PortfolioHUB/docs/slides/
- Localmente: clone o repositório e abra `index.html` no navegador. Não há build nem dependências.

```bash
git clone https://github.com/murilobarbosaa/PortfolioHUB.git
cd PortfolioHUB
```
